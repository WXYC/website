Before you start

01

Claim it out loud

Say in Slack which card you're taking and comment on the linked epic, so two people don't quietly start the same thing. Claim the epic, not one ticket — that's how it survives past the first PR.

02

Read the repo's CLAUDE.md

Every repo has one: patterns, env vars, test conventions, the local gotchas. Python repos also point at the shared test patterns in the wiki.

03

Ask where the fence is

For anything in Tier 3, ask which files are yours and which are frozen before you write code. The cards flag what's known, but the freezes move.

04

Small PRs, green CI

Aim under a thousand lines, run lint and tests locally first, then rebase-merge. If a review is sitting for more than a day, say something — that's a bug in us, not in you.
